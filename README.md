# 3D-Files-and-code-for-Soft-Robotic-Gripper
All code and 3D model files, including original CAD source files (Fusion 360) are available for replication within this repository. 

The mainStructure.stl file prints the housing for the actuators and palm sensor.

The actuator (top, mid, bottom) files print the pieces to assemble the mold for the sillicon actuator.

The sensor files print the pieces to assemble the mold for the palm sensor. 

The code for the arduino is found in files Sensor.cpp, Sensor.h, and projectCode.ino (the main).

The visualization code for the Processing application can be found in arduinoVisualization.pde.
